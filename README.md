# Axida Lab Website

A responsive, English-language academic lab website built with plain HTML, CSS, and a small amount of JavaScript. No build tools or server-side code are required.

## Files

- `index.html` — page content and sections
- `style.css` — layout, typography, colors, and responsive styles
- `script.js` — mobile navigation and dynamic copyright year
- `images/` — reserved for approved team photographs and other local assets

## Deploy to GitHub Pages

1. Open the `Axida-Lab/axida-lab.github.io` repository.
2. Upload the contents of this folder to the repository root (not the enclosing `Axida_Lab` folder).
3. Commit the files to the `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Visit `https://axida-lab.github.io/`. The first deployment may take a few minutes.

## Editing

Edit text directly in `index.html`; adjust visual styles in `style.css`. Upload the changed files to the repository and commit. GitHub Pages will publish the update automatically.
